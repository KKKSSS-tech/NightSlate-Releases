# NightSlate support

Use [GitHub Issues](https://github.com/KKKSSS-tech/NightSlate-Releases/issues) for installation questions, update failures, and reproducible defects.

Before posting, remove personal information, download registration details, local file paths that contain your account name, and any private keys or credentials. Include the NightSlate version, operating system version, DaVinci Resolve edition, and the exact on-screen error. Do not attach DaVinci Resolve installers.

Security-sensitive reports must use [private vulnerability reporting](https://github.com/KKKSSS-tech/NightSlate-Releases/security/advisories/new), not a public issue.
