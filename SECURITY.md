# Security policy

NightSlate accepts private vulnerability reports through [GitHub Security Advisories](https://github.com/KKKSSS-tech/NightSlate-Releases/security/advisories/new).

Please include affected versions, operating system, reproduction steps, expected impact, and any suggested mitigation. Do not publish exploit details or personal registration data in a public issue.

Security fixes are provided for the latest public NightSlate release. A report is acknowledged after it is reviewed; remediation timing depends on severity and reproducibility.
