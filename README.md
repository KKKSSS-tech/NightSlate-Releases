# NightSlate Releases

This repository is the official public channel for NightSlate downloads, signed update metadata, release notes, and support links.

NightSlate helps users check, download, and—only after explicit opt-in—install verified official DaVinci Resolve updates during a configured maintenance window. NightSlate is an independent third-party project and is not affiliated with or endorsed by Blackmagic Design.

## Release status

Public binaries are still being prepared and verified. Until a signed release appears on the [Releases page](https://github.com/KKKSSS-tech/NightSlate-Releases/releases), there is nothing to download from this repository.

## Safety

Download NightSlate only from this repository. Each release will include checksums and signature information. NightSlate does not redistribute DaVinci Resolve installers; it uses Blackmagic Design's official download service and preserves the required registration flow.
